# Immutable v6 fixture corpus

This directory preserves the complete 14-case source, report, and Semantic IR
corpus emitted under `codeskeptic.semantic-verification/v6` before A7.3 added
the proof-neutral Memory IR v7 representation.

`SHA256SUMS` covers the archived manifest, every source case, and every expected
artifact. These files are historical wire evidence and must not be rewritten.
