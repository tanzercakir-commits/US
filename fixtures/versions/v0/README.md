# v0 Fixture Archive

This directory is the immutable five-case corpus frozen by F4.1 before the
A4.1 counterexample-evidence migration to schema v1.

The JSON and IR bytes are historical artifacts and must not be regenerated or
rewritten. Their serialized `source` paths intentionally retain the original
`fixtures/cases/...` display paths from the time they were produced. The copied
`cases/` and `manifest.json` preserve the complete corresponding inputs and
expected summaries.

Current fixtures remain under `fixtures/cases`, `fixtures/manifest.json`, and
`fixtures/expected`.
